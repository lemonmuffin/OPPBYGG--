##  Overview

**OPPBYGG**는 미지의 외계 행성을 탐험하고, 자원을 채취하며, 생산 시설과 자동화 인프라를 구축하는 VR 행성 개척 및 공장 자동화 시뮬레이션입니다.

플레이어는 척박하지만 독특한 환경을 가진 여러 행성에 진입해 주변 지형과 자원을 직접 조사합니다. 채취한 자원은 가공 기기, 건축 자재, 고도화된 생산 설비로 변환되며, 각 공정은 점차 서로 연결된 하나의 거대한 생산 시스템으로 발전합니다.

손으로 장비를 조작하고, 직접 건물을 배치하고, 생산 라인의 흐름을 눈앞에서 확인하는 경험을 통해 단순한 자원 수집을 넘어 살아 움직이는 외계 산업 기지를 완성하는 것이 핵심입니다.

##  Key Features

###  VR 기반 몰입형 조작 및 탐험
* **표준 VR 이동 지원:** 텔레포트와 스무스 이동을 자유롭게 선택 및 활용 가능합니다.
* **물리 기반 인터랙션:** 모션 컨트롤러를 활용한 손동작 기반의 자연스러운 장비 조작 및 자원 상호작용을 지원합니다.
* **탐험 중심 플레이:** 외계 행성의 지형, 환경, 특수 구조물을 직접 관찰하고 조사합니다.

###  자원 채취 및 공정·건설 시스템
* **단계별 자원 가공:** 행성별 독특한 외계 원자재를 채취하여 기초 자재부터 고도화된 고급 자재까지 가공 체인을 구성합니다.
* **자유로운 건설 및 꾸미기:** 채취한 자원으로 가공 기기, 생산 설비, 인프라 건물뿐만 아니라 플레이어의 취향을 반영한 공간 꾸미기를 지원합니다.

###  멀티 행성 자동화 및 인프라 구축
* **전 행성 자동화:** 생산 공정을 연결하여 원재료 투입부터 완제품 생산까지의 흐름을 자동화합니다.
* **행성 간 물류 확장:** 인접한 여러 외계 행성의 생산 거점을 연결하여 하나의 통합된 대규모 자동화 시스템을 구축합니다.

##  Game Goals

OPPBYGG의 최종 목표는 모든 행성을 탐험하고 자원 생산을 완전 자동화하여 자신만의 거대한 공장을 완성하는 것입니다.

1. **외계 행성 탐험:** 미지의 행성을 탐험하고 독특한 외계 자원을 발견합니다.
2. **기초 설비 구축:** 자원을 채취하여 기초 가공 설비와 건축 자재를 제작합니다.
3. **공정 연결 및 확장:** 생산 라인을 연결하여 자동화 인프라를 점점 확장합니다.
4. **청사진(Blueprint) 해금:** 고도화된 자재를 투입해 새로운 기능과 설비의 청사진을 모두 획득합니다.
5. **통합 자동화 달성:** 해금한 청사진으로 나만의 공장을 완공하고, 모든 행성의 자원 생산 및 자동화를 완료합니다.

##  Controls & Interaction

| 기능 | 기본 방식 | 설명 |
| :--- | :--- | :--- |
| **이동** | 텔레포트 / 스무스 이동 | 플레이어의 멀미 민감도와 플레이 스타일에 맞춰 이동 방식을 선택합니다. |
| **시점 회전** | 스냅 턴 / 부드러운 회전 | VR 환경에 맞춰 시야 회전 방식을 설정할 수 있습니다. |
| **물체 상호작용** | 모션 컨트롤러 | 자원, 도구, 부품, 장비를 직접 잡고 이동하거나 배치합니다. |
| **장비 사용** | 손동작 및 버튼 입력 | 도구를 들고 자원을 채취하거나 생산 장비를 직접 작동합니다. |
| **건설** | 설계 모드 / 직접 배치 | 해금한 청사진을 선택하고 원하는 위치에 건물과 설비를 배치합니다. |
| **메뉴 / 인벤토리** | VR UI | 손목형 또는 컨트롤러 기반 UI를 통해 설계도와 자원을 관리합니다. |

>  *실제 버튼 배치는 타겟팅하는 VR 플랫폼 및 컨트롤러 표준에 따라 조정될 수 있습니다.*

##  Tech Stack & System Architecture

### Tech Stack (예시 스택)

| 영역 | 예시 기술 | 적용 목적 |
| :--- | :--- | :--- |
| **게임 엔진** | Unreal Engine | VR 렌더링, 물리, 씬 관리 및 배포 |
| **VR 표준** | OpenXR | 다양한 VR 디바이스 및 입력 시스템 호환성 확보 |
| **VR 인터랙션** | XR Interaction Toolkit / Unreal XR | 손, 컨트롤러, 물리 잡기 및 UI 인터랙션 구현 |
| **스크립팅** | C# / C++ | 게임플레이, 생산 로직, 저장 시스템 처리 |
| **물리 시스템** | PhysX 기반 물리 Engine | 자원 채취, 오브젝트 운반 및 장비 상호작용 |
| **데이터 관리** | ScriptableObject / Data Asset / JSON | 자원, 레시피, 청사진, 설비 속성 데이터 관리 |
| **자동화 시스템** | 생산 그래프, 이벤트 기반 파이프라인 | 자원 흐름, 벨트·파이프 네트워크 연결 시뮬레이션 |
| **버전 관리** | Git, GitHub, Git LFS, 노션 | 소스 코드, 대용량 VR 에셋 및 프로젝트 관리 |

### System Architecture Layout

```text
├── World Layer        : 행성, 지형, 환경 및 탐험 영역 관리
├── Resource Layer     : 자원 생성, 채취 상태, 인벤토리 관리
├── Production Layer   : 레시피, 가공 설비, 생산 큐, 자원 변환 처리
├── Automation Layer   : 생산 라인, 운송 네트워크, 행성 간 물류 흐름 관리
├── Construction Layer : 청사진 해금, 건물 배치, 건설 유효성 검증
├── Interaction Layer  : VR 입력, 잡기, 도구 사용, 피드백 처리
└── Persistence Layer  : 플레이어 진행도, 행성 상태, 자동화 구성 저장/불러오기
